# VOXA 模型编辑器

VOXA 编辑体素模型、皮肤与动画。Creator 可打开独立模型库，也可在地图内嵌入项目模型编辑；模型保存范围由当前工程上下文决定。

## 启动与数据

| 方式         | 命令 / 地址                                                       |
| ------------ | ----------------------------------------------------------------- |
| 完整源码栈   | 根目录 `npm run dev:infra`，默认 `http://127.0.0.1:3123/`         |
| 独立界面调试 | `npm --prefix apps/voxa run dev`，默认 `3001`，仍需身份服务与配置 |
| 开发模型数据 | `.local-data/apps/voxa/data/`                                     |
| 调整数据路径 | `BOX_DEV_DATA_DIRECTORY` 或单独设置 `VOXA_DATA_PATH`              |

玩家需获授创作端和“管理模型”能力。首次授权与模型制作见[首个作品教程](../../docs/first-project.md)。`.voxaproject` 用于模型工程导出；旧包缺少 mesh 等资源时，需打开后重新保存。

## 导出模型预览

在文件菜单选择“导出 → 导出预览包 (.voxaplay)”，填写作者、版本、作品简介并选择默认动画后导出，再到玩家后台“游玩管理 → 模型预览”上传。上传后会发布到 Play 的“模型预览”列表，可编辑名称、作者、版本与简介，下架或删除。打开预览会自动播放导出时选择的默认动画；选择静态或使用旧包时显示静态姿态。点击模型卡片会在当前列表页内打开预览，关闭后保留列表位置。预览支持左右键拖动旋转、中键拖动平移、滚轮缩放、重置视角、显示网格与方向箭头及切换、播放和暂停动画；单个包最大 32MB。材质发光默认开启，可通过底部按钮切换；右下角提供鼠标操作说明。“分享模型”可复制独立预览链接。模型渲染资源会按版本和内容校验值存入浏览器 Cache Storage；再次打开同一版本时读取本地缓存，更新版本后刷新缓存。浏览器不支持缓存或空间不足时仍可在线预览。

服主或高级管理员可直接管理；委派管理员需在“服主管理 → 权限组 → 游玩管理 → 模型预览”授予“查看模型预览”或“管理模型预览”。管理权限包含查看权限，地图管理权限不自动授予模型管理权限。

`.voxaplay` 只保存烘焙后的渲染网格、材质、节点变换、动画和可选封面，不包含可编辑体素、工程组织、撤销历史或其他工程状态。它不能通过 VOXA 工程导入功能打开，重命名为 `.voxaproject` 也无效。浏览器预览必须读取网格，文件格式不承诺阻止逆向提取；渲染数据不足以还原完整工程。继续编辑或备份请使用 `.voxaproject`。

## 编辑器快捷键

| 快捷键                                  | 操作                     |
| --------------------------------------- | ------------------------ |
| `Cmd/Ctrl + S`                          | 保存当前工程             |
| `Cmd/Ctrl + O`                          | 打开历史面板             |
| `Cmd/Ctrl + Z` / `Cmd/Ctrl + Shift + Z` | 撤销 / 重做              |
| `Backspace`                             | 删除当前选中内容         |
| `Cmd/Ctrl + A` / `Cmd/Ctrl + D`         | 全选 / 取消选择          |
| `Space`                                 | 播放 / 暂停动画          |
| `F`                                     | 聚焦当前选中部件或模型   |
| `G`                                     | 显示 / 隐藏网格          |
| `P`                                     | 在透视与正交视图之间切换 |
| `←` / `→`                               | 上一个 / 下一个关键帧    |
| `Home`                                  | 时间轴回到起点           |

输入框获得焦点时，编辑器不会拦截这些按键；浏览器或系统保留的组合键也不会被覆盖。

## 代码入口

| 位置                                  | 职责                     |
| ------------------------------------- | ------------------------ |
| `pages/index.tsx`、`pages/api/local/` | 页面门禁、模型与资源 API |
| `server/local-voxa-store.ts`          | 模型索引、blob 与快照    |
| `server/local-voxa-project-bundle.ts` | 模型工程包读写           |
| `src/models/`、`src/views/`           | 编辑、动画和保存界面     |
| `lang/src/`                           | 翻译源文件               |

## 按需检查

在根目录使用 `npm --prefix apps/voxa run <脚本名>`：

| 脚本                                                    | 内容                     |
| ------------------------------------------------------- | ------------------------ |
| `check:model-library-scope`                             | 独立模型库和项目模型范围 |
| `check:model-project-bundle`                            | 工程包与资源             |
| `check:local-cors`、`check:model-management-permission` | 来源和模型权限           |
| `check:default-skin-scope`、`check:parent-storage-url`  | 默认皮肤和父页面资源地址 |
| `build`                                                 | 编译翻译与应用           |
| `update-i18n`、`build-i18n`                             | 提取和构建文案           |

检查不属于默认 Verify；保存、放入地图和发布后的资源仍需实际验收。模型库与上传文件不提交到源码，测试范围见[检查与测试](../../docs/testing.md)。
