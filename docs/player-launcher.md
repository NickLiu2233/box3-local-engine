# 玩家启动器使用与维护

更新日期：2026-10-13。本文描述 Electron 玩家启动器，不是 Tauri 引擎部署管理器；玩家版本与引擎版本分别管理。

## 连接服务器

添加玩家可访问的 **Play 地址**，不是 Creator、玩家后台或 Web 管理端地址。例如 `http://10.240.28.131/abc`，路径前缀必须完整保留。

省略协议时，本机与 RFC1918 内网 IPv4 默认 HTTP，公开 IP 和域名默认 HTTPS；显式协议优先。部署管理器还会参考证书配置推导协议，不与玩家输入规则混用。启动器通过服务器引导接口识别服务、登录入口和签名公钥，登录门户可以有自己的域名或路径。

连接失败先核对服务是否运行、地址、前缀和证书。不要通过关闭证书、签名或身份校验解决连接问题。

## 账号与游玩

登录后选择服务器开放的地图开始游玩。账号设置只修改当前服务器的显示昵称与内置皮肤，用户名由服务器管理。保存成功关闭弹窗，失败保留输入并显示错误；过期会话要求重新登录。

桌面输入支持系统复制、粘贴、剪切和全选快捷键，隐藏菜单不取消快捷键。这与网页 Clipboard API 权限是不同机制。已运行地图再次启动时聚焦现有窗口。

## 网络与缓存

HTTPS 和本机回环 HTTP 支持 Service Worker 缓存；非回环 HTTP 继续在线游玩，跳过可选预缓存。缓存按服务器隔离，资源清理不等于删除服务器账号。移除服务器清理本机对应会话与缓存；游戏运行时先关闭窗口再清理。

同域路径部署时，页面、图片、Worker、API 和资源请求都应保留服务前缀。不要把多个服务的 `/_next/` 统一转给一个上游，它们不是同一份构建资源。缓存命中不代表可以离线登录或脱离权威服务器运行。

| 现象                | 排查方向                                           |
| ------------------- | -------------------------------------------------- |
| 地址无法识别        | Play 地址、协议、前缀和服务运行状态                |
| 登录后回到登录页    | 会话过期、设备失效、门户回跳与 Cookie 路径         |
| 图片或 chunk 404    | 请求前缀、对应构建产物、旧页面缓存                 |
| 一直显示正在保存    | 安装包是否包含请求生命周期修复、实际请求状态与响应 |
| HTTP 下 COOP 被忽略 | 浏览器可信来源限制；与资源 404 和接口失败分别排查  |

反馈时提供启动器版本、公开地址、失败请求路径和状态码，不提供密码、Cookie、启动票据或完整认证请求。
