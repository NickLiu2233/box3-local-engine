# 反作弊验证记录

日期：2026-10-06。测试仅使用隔离进程、虚拟玩家和本机临时端口，没有运行外挂或操作真实玩家。

## 已复现并修复的风险

| 原问题 | 修正 |
| --- | --- |
| 尚未加入的连接跳过监听进入业务处理 | 仅连接维护可在这一阶段继续；GUI、交互、自定义事件另有基础连接状态校验 |
| 畸形输入被分类器静默跳过 | 格式错误明确拒绝，不当作正常的不匹配消息 |
| 初始化订阅在 RUNNING 前被丢弃 | 可信脚本初始化与运行阶段分开验证 |
| 脚本退出后删除监听造成直接放行 | 保持已启用的保护，直到新的可信脚本完成初始化 |
| 分类监听延迟无关 GUI 回复、网络维护 | 主机按实际协议分类路由，避免占用无关消息的检查队列 |
| 玩家冒用他人 GUI 回复、旧回复命中新脚本 | 绑定真实玩家连接和发起请求的脚本，签发不随脚本局部计数器重置的返回编号 |
| 仅凭连接标识追加 WebSocket 通道 | 首连接与附加连接均需会话绑定凭证，验证签名、有效期和连接归属 |
| 无自身移动数据时仍修正共享物体 | 客户端只可修正自身角色，其他实体由服务器控制 |
| 同一输入重复携带自身修正，只检查第一条却应用全部 | 重复自身 ID 的候选修正丢弃；检查队列只保存唯一已检查候选的快照，不影响普通按键 |

GUI 返回归属、WebSocket 凭证和自身角色修正限制不依赖服主编写判断规则。

原有 22 项 Node 回归之外，新增 5 项逐次操作测试及 3 项重复移动修正测试。总计 30 项，另有桥接和原生隔离独立回归、服务端类型检查、脚本沙箱构建、既有处罚接口回归和 DTS 编辑器提示检查。

重复修正测试先在旧实现失败：真实 Mu 编码/解码保留了两个自身 ID，监听只看到第一条，业务队列却保存两条。修复后，订阅和未订阅两条路径都丢弃重复自身修正；直接调用检查队列也不能绕过。正向测试确认唯一自身候选仍可批准，网络对象复用、暂停、锁定、旧帧和断开校验仍有效。

## 对照 Anti 样本新增的验证

仅静态阅读 `/Users/viyrs/Downloads/Anti`；没有执行用户脚本、运行其辅助工具或连接外挂外部服务。没有把外挂代码复制进引擎。

| 样本行为 | 引擎支持与验证 |
| --- | --- |
| `dao3-dape.user.js` 的 KillAura/ VoidPuller 修改其他实体位置与速度 | 原有所有权检查拒绝非自身角色修正；不依赖地图规则 |
| `setServerBlock.user.js` 自报远处射线起点和方块坐标 | 新增 `onAction`，完整提供候选射线和服务端位置，由服主配置自己的范围、相机和遮挡规则 |
| `BaseFunc.ts` 一条输入消息生成多个重复攻击事件，同时保持普通 inputState | 新监听按逐次事件展开，不从 inputState 推断或合并攻击；测试规则能拒绝此消息 |
| FakeAdmin 在浏览器修改配置响应 | 不修改真实服务器权限；监听与决策协议只在私有脚本传输端注册 |

真实网络测试覆盖玩家 Mu 编码 → 主机检查 → 私有脚本 `onAction` → 放行/拒绝 → 实际 NetServer 输入处理。拒绝时事件队列为空，允许时发送者仍是连接绑定玩家。

这个测试还发现并修正了向量转换问题：真实输入使用 Float32Array，检查副本之前把它转成 `{0:...,1:...,2:...}`，与分类器期待的数组不一致；现在保留为数值数组。原始字节消息仍只提供长度。

新增接口不会自动识别合法格式的作弊输入。测试中的次数限制仅是服主规则示例，不是引擎强制冷却或攻击距离。服主须结合玩法检查起点、命中、权限和频率；没有订阅时保留原有业务路径。

对抗分支包括伪造身份字段、错误脚本来源、跨玩家决策、旧回复重放、替换登录身份、超时、畸形数据、其他实体修正、缓存对象复用、暂停和旧帧过期。正常输入、合法 GUI 回复、合法多通道和主动移除监听的重载也有正向检查。

原生隔离测试夹具最初未显式释放 Context，退出时触发清理问题；按实际运行时已有的释放顺序调整后，普通模式与测试模式均复跑通过。

## 仍需确认的事项

- 这些测试不等于对全部引擎代码完成渗透测试，不能承诺所有外挂都会被识别。
- 判断规则仍由服主编写；不校验权限的自定义服务端脚本，不能靠只读事件自动变安全。
- 共享物体改为服务端计算后，推箱子、载具、多人高延迟场景的视觉和同步手感还需真人回归。
- 公网 HTTP 下的窃听、凭证泄露不在这些监听器的可解决范围内，长期对外部署仍建议 HTTPS/WSS。
- 本轮修正尚未进入运行中的镜像和桌面安装包，需要同时更新 Creator、Play 前后端并刷新游戏页面。
