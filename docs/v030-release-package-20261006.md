本包按本地候选构建，校验使用脚本支持的 `BOX_ALLOW_DIRTY_RELEASE=true` 候选模式。默认正式发行校验会拒绝 `local-dirty`，未修改这项规则。macOS 尚未完成 Developer ID 签名及 Apple 公证。
