## 2026-10-09 源码更新补充

本节按最近 Git 提交追加；上面的历史交付物、校验值和验证范围保留，不能用它们证明本节新增代码已进入该历史安装包。

### 公网访问与部署

- 支持独立和共用公网地址。共用模式可用服务端口或路径分流，模式切换保留独立地址和共用路径草稿。
- 域名和 IP 可省略协议，根据完整的新证书或已保存证书自动选择 HTTPS/HTTP；显式协议及端口优先，HTTPS 支持自定义端口。
- 默认选择内置 Nginx，保留明确保存的外部选择；内置入口接管公网端口，本机外部入口使用独立 loopback 上游端口。
- 路径入口适配页面、静态资源、登录门户、后台管理、实时连接和 Service Worker 资源缓存；旧镜像缺少路径能力时在应用前提示更新。
- 完善证书复用、共用证书清除及失败回滚，修复右上角提示被处理中遮罩覆盖的问题。

### 工程与文档

- 公网路径去除首尾斜线后限制为 128 个字符，前后端统一校验字符与保留路径。
- 拆分证书生命周期、Nginx 容器参数、路由规划和配置应用职责，统一默认来源解析，整理 Rust 格式。
- 将公网模块结构检查和界面回归接入仓库检查流程，修正过时的桌面/Web 契约检查。
- 更新 [Nginx 与公网证书配置](./https-certificate-management.md)、[配置参考](./configuration-reference.md)及文档索引；日期记录作为历史方案保留。模块职责见 [公网路由工程说明](./public-routing-engineering.md)。
