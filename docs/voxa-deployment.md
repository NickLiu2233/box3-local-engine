# VOXA 本地模型编辑器

VOXA 用于编辑本地模型、皮肤和动画工程，默认在本机使用，并跟随 Creator 的访问模式。模型需要被放入并保存到地图工程后，才会成为地图可发布资源。

## 启动

```bash
pnpm voxa
pnpm voxa:up
```

桌面用户可从启动器启动 VOXA。Creator 与 VOXA 应使用同一部署的数据根；端口变化不迁移模型或工程。

## 工程包

`.voxaproject` 用于继续编辑模型工程。旧工程包若不包含 Blob，无法在本地凭空恢复资源，应回到原工程重新导出。

VOXA 公网访问风险较高，只应在 HTTPS、网络访问控制和模型管理权限均已配置时启用。不要把本地模型库、项目资源或备份提交到仓库。地图发布与资源边界见[项目与发布包](./projects.md)。

## 与 Creator 配合

在 VOXA 创建或编辑模型、皮肤、动画后，将素材放入 Creator 地图并保存。只有被项目引用的资源会随项目和发布包携带；VOXA 本地库本身不会自动打进 Play。

升级或迁移前导出 `.voxaproject`，并备份引用这些素材的地图工程。模型工程和地图工程属于不同格式，不能互相替代。
