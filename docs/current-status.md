# 当前版本与文档范围

整理日期：2026-10-08。当前主项目源码版本：`0.3.0`，以根目录 `package.json` 为准。
这不是声明远端 CDN、已安装 App 或正在运行的容器已经更新到此源码。

## 已有能力

- Creator、Play、VOXA、Player Service、参考登录门户，以及桌面和 Linux Web 管理端。
- 地图组、工程发布与导入、玩家账号、后台权限、地图运行容器及持久数据。
- 服务端 `world.moderation` 地图授权；图主自定义 `world.anticheat` 规则与拒绝审计。
- 可替换的 TypeScript 登录门户模板、修改密码及独立模板导出。
- 共用公网地址与单服务覆盖，显式 HTTP/HTTPS 配置，实时 WS/WSS 连接。
- 已移除程序许可证激活、设备绑定、在线取时和到期检测；账户与服务端权限校验仍保留。
- 项目代码采用 MIT，源码访问目前先邀请制；内部迁移器已移到仓库外。

上面的反作弊能力不等于所有地图自动防住所有外挂。地图规则需要校准，不能把检查失败直接当作作弊。
地图脚本插件系统仍是讨论方向，不是已经安装可用的产品功能。
