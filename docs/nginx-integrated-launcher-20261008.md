# Nginx 与现有公网配置整合记录

日期：2026-10-08；版本：v0.3.0。

## 完成的行为

- 移除独立 HTTPS 与证书管理面板。Nginx 来源和托管入口启停放入数据服务。
- 支持单独下载官方 Nginx 镜像或复用本地镜像；支持已安装或自行配置的外部 Nginx，外部服务不要求是镜像。
- 证书位于原有共用地址和各服务独立公网地址下，不再重复输入域名；随原有“保存配置”提交。
- 支持每个服务单独证书、共用证书、复用已保存证书。更新共用证书保留已配置的独立证书。
- 外部模式使用管理端 OpenSSL 校验证书，不运行 Nginx 镜像；生成配置供部署者在目标 Nginx 校验并重载。
- 托管入口继续保留配置校验、所有权校验、失败回退和 HTTPS/WSS 转发，并检查监听端口冲突。旧单证书配置仍可读取。

共享管理模块回归：88 项通过，1 项 Docker 验收默认忽略；该验收另行执行并通过。界面与传输回归：29 项通过。桌面与 Web 管理端编译通过，界面生产构建通过。

实际打开 macOS 应用，确认数据服务出现 Nginx 的“已有外部 Nginx（连接已有服务）”选项，公网各现有地址下面出现证书区域，旧独立面板消失。现场仅检查页面，未导入真实证书、应用新的 HTTPS 入口或改变用户公网地址。
