# 访问配置冲突审查

> 技术验收记录：下文是特定修复与隔离环境的结果，不是当前全仓或公网验收证明。操作以[Nginx 指南](./https-certificate-management.md)和[玩家启动器](./player-launcher.md)为准。

本次检查覆盖桌面与 Linux Web 管理端的配置保存、旧配置迁移、运行环境生成、Nginx 端口接管、HTTPS 与来源校验，以及玩家启动器登录链路。

## 已修复

| 场景                             | 原问题                                 | 修复后                                           |
| -------------------------------- | -------------------------------------- | ------------------------------------------------ |
| Play 公网 HTTPS，创作端本机      | 创作端和 VOXA 被生成 HTTPS 回环地址    | 每个服务组按自己的访问模式生成协议               |
| 公网切回本机或局域网             | 旧 URL 和登录覆盖值继续生效            | 草稿保留，运行值不使用旧公网覆盖                 |
| 配置了 HTTPS 登录入口            | 遗留内网登录 URL 覆盖最终公开入口      | Nginx 登录路由与公布的登录 URL 一致              |
| 登录门户经过 HTTPS 代理          | 按容器内部 HTTP 判断来源，拒绝正确请求 | 使用配置的公开 origin，兼容合法直接同源访问      |
| 运行于 HTTPS 的 Play / ARENA     | Compose 未传入各自的公开服务器地址     | Cookie / 会话协议判断获得对应服务的公开 URL      |
| 共用域名和不同路径               | 登录路径被丢弃，或被启动器桥接拒绝     | 引导、登录、退出保留门户前缀，权限只覆盖指定前缀 |
| 切回非公网，旧 Nginx 路由仍保存  | 应用端口继续被移除                     | 只接管当前仍为公网的服务端口                     |
| Play 与创作端使用不同访问模式    | 界面链接和路由跟随 Play 模式           | 按服务组显示链接和生成路由                       |
| Linux Web 管理容器使用外部 Nginx | 尝试在容器内检测、重载宿主机进程       | 导出宿主机可用的配置，由服主检查并重载           |
| 外部 Nginx 接管端口              | 后端端口和证书路径仍引用容器布局       | 分配回环上游端口，导出宿主机证书路径             |

允许来源仍按最终 URL 的 origin（协议、域名、端口）生成；路径用于路由，不加入 origin。密钥、来源和签名校验没有放宽为任意来源。

补充修复了同一公网端口的 HTTP/HTTPS 切换：是否重建入口容器按完整的“公网端口 → 内部监听端口”映射判断。公网 TLS 探测也区分 IP 与域名，并跳过普通 HTTP 入口。

补充修复桌面端路径应用的适配层：生成函数原来返回原始 `.env`，而非已经写给 Docker 的完整运行配置，导致入口路径检查缺少 `BOX_IMAGE_TAG`。现统一返回完整运行配置；显式指定完整镜像名时，也不再强制要求默认镜像版本。新增桌面原生调用链和显式镜像的回归测试。

## 验证

- Rust 管理核心和 Web 管理端单元测试。
- 管理界面与传输层回归测试，包括 Linux 外部 Nginx、访问模式切换和证书应用。
- 登录门户类型、构建及接口测试，包括 HTTPS 代理来源。
- 玩家启动器类型、构建与完整测试；同域 `/play` 和 `/accounts` 的引导、登录、退出链路测试。
- Play 引导接口与签名资源包测试。
- 9 种 IP / 域名 / 协议输入，每种经历公网→本机→局域网→公网→本机→公网，共 54 轮保存、模式切换和重载；确认运行 URL、登录 URL、绑定地址与地址草稿一致。
- 真实 Docker Nginx 验证域名 HTTPS、IP SAN 的 HTTPS、普通域名 HTTP、普通 IP HTTP、WSS、证书错误拒绝和配置回滚；反复切换 IP / 域名及 HTTP / HTTPS，并检查响应确实来自 Play。
- 公网 TLS 探测回归覆盖 IPv4、IPv6、域名和混合 HTTP / HTTPS 入口。

## 上线范围

以上为源码和隔离环境验证，没有修改远程服务器的配置。需要更新 Web 管理端、Play / ARENA、登录门户和玩家启动器；保存访问配置后生成新运行配置。外部 Nginx 需要在宿主机导入新配置、检查并重载。

公网登录页面必须填写玩家可访问的地址。仅填写 HTTPS 地址不代表证书和外部代理已部署。实际服务器还需要核对域名解析、监听端口、证书域名与防火墙规则。
