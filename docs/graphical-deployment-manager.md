# 图形化部署管理器

桌面启动器负责按需下载与校验引擎镜像、配置保存、服务启动停止、实时进度、状态、性能查看和工程备份。关闭窗口不会停止容器。

当前版本无需许可证激活、设备绑定或续期。源码仓库邀请与服务登录是两回事，见[源码访问说明](./source-access.md)。

## 使用步骤

1. 选择内置或外部 PostgreSQL；Redis 可选择不启用、内置或外部服务。
2. 设置访问模式、端口、容量；服务密钥由启动器生成，按用途保管。
3. 启动“创作端”“游玩端”或“全部服务”；首次启动自动下载当前版本与架构的引擎镜像，显示下载和导入进度。
4. 从服务总览打开已启动的地址并确认健康状态；详细日志使用 Docker Desktop 或 Docker CLI 查看。

启动器和 Linux Web 管理端都可管理 Creator、Play、VOXA、Player Service 和登录门户。桌面启动器的数据位于系统应用数据目录的 `runtime/`；关闭窗口或升级程序不会停止容器，也不会自动删除运行数据。

Creator、VOXA 默认使用本机模式，也可选择局域网或公网；公网创作会显示安全警告，应使用 HTTPS、访问控制和最小创作者权限。启动器的地图备份不包含 PostgreSQL，数据库需单独备份。

| 模式            | 启动器行为                                                               |
| --------------- | ------------------------------------------------------------------------ |
| 内置 PostgreSQL | 从 DaoCloud 下载 PostgreSQL 16，生成随机身份，启动后展示可复制的连接信息 |
| 外部 PostgreSQL | 保存服主填写的地址、数据库名、账号和 SSL 参数，并提供连接测试            |
| 内置 Redis      | 从 DaoCloud 下载 Redis 7，生成随机密码，固定展示业务 DB 0 与缓存 DB 1    |
| 外部 Redis      | 保存地址、端口、密码和 DB 分配；服务不可用时游戏运行时使用安全回退       |
| 不启用 Redis    | 不启动 Redis；不影响玩家、权限和地图持久数据                             |

内置 PostgreSQL/Redis 只监听 `127.0.0.1`。数据库卷、工程目录、地图库和 `box-play-runtime-cache` 的删除与备份边界见[本地基础设施](./local-infrastructure.md)；镜像源、端口和外部连接变量见[配置参考](./configuration-reference.md)。

## 页面与数据

公网支持独立地址或共用地址，共用模式通过端口或路径区分服务；裸域名/IP 根据证书自动选择协议，显式 HTTP/HTTPS 优先。数据服务默认选择内置 Nginx，保存过的外部选择保留。外部 Nginx 模式显示手动配置示例；内置模式支持上传证书或填写文件路径，路径文件更新后自动校验并重载，也可点击 Nginx 的“重载”。地址与证书流程见[Nginx 配置](./https-certificate-management.md)。公网 HTTP 的浏览器限制见[HTTP 兼容说明](./http-compatibility.md)，登录镜像定制见[门户模板](./self-hosted-login.md)。

- **服务总览**：启动、停止、打开地址并自动查看健康状态；服主密钥默认掩码，点击复制图标复制。
- **数据配置**：PostgreSQL、Redis、端口、共用/单服务公开地址、登录门户镜像、容量、地图库、注册开关和密钥。
- **数据与备份**：工程备份的创建、导入、导出和恢复；备份包含地图数据、游玩包、VOXA 本地资源和根目录 `.env`（含密码、密钥与访问配置，请妥善保管）。恢复前会停止相关服务；恢复时单独提示是否用备份中的 `.env` 覆盖当前配置。
- **性能监控**：查看容器 CPU 与内存趋势，用于调整地图运行时额度。
- **工程运行时**：按创作端、游玩端分别列出主地图和副地图；运行中的地图显示其进程树最近 1 秒的 CPU 平均值、RSS 内存和运行时长。窗口退到后台时自动降为 5 秒刷新，回到前台立即恢复。`100%` 代表一个 CPU 核心，空闲地图显示 `0.0%` 属于正常状态。
- **游戏内关于**：Play 菜单展示构建版本；发行构建注入提交元数据后显示 `版本-local · 提交短号`，开发构建缺少提交元数据时只显示版本。

“全部服务”启动 Creator、VOXA、Play、Player Service 和登录门户；“创作端”不启动 Play；“游玩端”不启动 Creator 和 VOXA。停止只停止容器，不删除工程、地图库、备份、配置或数据库。

桌面启动器采用轻量发行包，不内置镜像归档；每个服务的下载信息、归档 SHA-256 和 Docker 镜像摘要固定在启动器内，与架构一起校验。下载失败可重试，Docker 导入失败保留已校验文件，导入成功后删除下载归档。升级启动器后，启动服务时只下载变化的镜像；相同摘要直接复用。新服务健康后才清理无容器使用的旧镜像，失败时保留旧镜像及回滚标签。独立打包和本地测试见[安装与运维](./installation-and-operations.md#桌面镜像的本地测试)。升级前导出重要工程与备份；如果只替换程序，系统应用数据目录中的运行数据会保留。
