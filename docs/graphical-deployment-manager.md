# 图形化部署管理器

桌面启动器负责离线镜像导入、配置保存、服务启动停止、实时日志、性能查看和工程备份。关闭窗口不会停止容器。

## 使用步骤

1. 配置 PostgreSQL；Redis 可选。
2. 设置访问模式、端口、容量和三个独立密钥。
3. 启动“创作端”“游玩端”或“全部服务”。
4. 从服务总览打开已启动的地址并查看日志。

启动器可管理 Creator、Play、VOXA、Player Service 和登录门户；Linux Web 管理端只管理游玩相关服务。运行数据保存在系统应用数据目录的 `runtime/`，升级程序不会删除它。

Creator、VOXA 只允许本机或局域网。公网使用 HTTPS 反向代理公开 Play 和登录门户。备份不包含远程 PostgreSQL，数据库需单独备份。

## 页面与数据

- **服务总览**：启动、停止、打开地址、查看健康状态和实时日志。
- **数据配置**：PostgreSQL、Redis、端口、访问范围、容量、地图库、注册开关和密钥。
- **数据与备份**：工程备份的创建、导入、导出和恢复；恢复前会停止相关服务。
- **性能监控**：查看容器 CPU 与内存趋势，用于调整地图运行时额度。

“全部服务”启动 Creator、VOXA、Play、Player Service 和登录门户；“创作端”不启动 Play；“游玩端”不启动 Creator 和 VOXA。停止只停止容器，不删除工程、地图库、备份、配置或数据库。

离线包内的启动器和镜像必须保持同一版本。升级前导出重要工程与备份；如果只替换程序，系统应用数据目录中的运行数据会保留。
