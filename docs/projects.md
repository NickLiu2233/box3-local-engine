# 地图、地图组与发布包

Creator 中的可编辑内容称为作品，Play 中称为地图。一个地图组由一个主地图和零到多个副地图组成：成员地图的地形、实体和脚本独立；共享资源和组数据可共用。

## 工作流

1. 创建主地图，按需新增副地图。
2. 编辑并保存所有成员。
3. 导出 `.boxproject` 继续协作，或发布 `.boxplay` 交给服主。
4. 在玩家管理后台的“游玩管理 → 游玩地图”审查并导入 `.boxplay`。

`.boxproject` 是可编辑工程包；`.boxplay` 是不含 Creator 源工程的只读运行快照。玩家管理后台可审查、开关和删除地图，但不能修改封面、标题、简介、作者或重新导出地图包。

完全离线发布请选择本地资源；引用 OSS 的发布包依赖发布者维护对象存储。客户端脚本和资源不可信，秘密、权限和胜负逻辑必须放在服务端。

## 编辑与发布边界

主地图可维护名称、作者、简介、封面、版本和更新说明；副地图维护自身名称与简介。地图组发布是原子操作：任一成员校验失败，不会留下半个新版本。

玩家管理后台在导入前显示地图组成员与已识别的服务端/客户端代码、图片和音频，审查过程不执行脚本。导入完成后，服主或拥有 `play-maps.manage` 的管理账号可临时关闭或删除地图组；关闭后首页与直接地图地址都会拒绝访问。

`.boxproject` 仅交给可信协作者。导入为副地图时，会加入目标地图组并共享该组资源；不要通过文件名覆盖或手工合并项目目录更新工程。
