# HTTP 访问兼容

引擎可以通过公网 IP、域名或局域网的 HTTP 地址使用。域名请明确填写 `http://`，不要因为填写了域名就自动改成 HTTPS。

## 正常使用的功能

登录、账号管理、地图编辑与游玩、图片和音频文件上传、资源 ID 生成、文件导入导出不应依赖 HTTPS。上传接口的文件哈希按文本解析；资源 ID 优先使用 `randomUUID`，不可用时使用 `getRandomValues`，不使用 `Math.random` 替代安全随机数。

复制按钮优先使用 Clipboard API；HTTP 下没有该 API，或浏览器拒绝权限时，尝试用户点击触发的传统复制。浏览器仍拒绝时不显示“复制成功”，提示手动复制。

## 浏览器限制，不能强行开启

| 能力 | 公网/局域网 HTTP 下的处理 |
| --- | --- |
| Service Worker 地图预缓存 | 跳过可选预缓存，继续在线加载地图。普通 HTTP 浏览器不能提供同等离线能力。 |
| 麦克风录音 | 明确提示当前 HTTP 地址不支持录音；不影响音频文件上传和播放。 |
| 存储容量统计 | 无法读取时返回未知，不误显示为 0，也不阻止其他操作。 |
| WebGPU | 项目中的实验性 WebGPU 模块已有能力检查；引擎现用 WebGL 路径不因此受限。 |

本机 `localhost`、`127.0.0.1` 等回环地址在支持的浏览器中可以视为安全上下文。判断能力时以浏览器实际提供的 API 和 `isSecureContext` 为准，不简单地把所有 HTTP 都判为不可用。

启动器要求签名验证的缓存流程仍会检查安全上下文，不能通过忽略签名或伪造缓存完成来兼容 HTTP。桌面启动器的 HTTP 在线游玩走现有在线加载流程。

## 安全边界

公网 HTTP 不加密，密码、会话和资源请求可能被网络中的第三方读取或篡改。兼容不等于安全；对外长期部署仍建议配置 HTTPS。不通过关闭 TLS 校验、放宽 CORS 或忽略身份验证来实现兼容。

## 回归检查

使用项目现有 `tsx` 运行：

```sh
tsx --test apps/game/scripts/check-http-compatibility.ts apps/game/scripts/check-resource-upload.ts
```

测试覆盖缺少 Clipboard API、剪贴板权限被拒绝、存储统计不可用、HTTP 录音限制、回环/HTTPS 录音能力，以及 HTTP 可选缓存降级。发布前还应在浏览器通过真实非回环 HTTP 域名和 IP 验证；只测 `127.0.0.1` 不能代表公网 HTTP。
