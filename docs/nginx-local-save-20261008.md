## 本轮行为

- 公网地址提示和 SSL 证书折叠栏保留 12px 间距。
- 移除独立“证书配置／导出 Nginx 配置”面板，证书随现有“保存配置”提交。
- Nginx 下载、启用与启动复用 Redis 的处理中弹窗，成功或失败显示结果；首次启用继续引导填写 HTTPS 地址和证书。
- 内置 Nginx 保存时自动应用证书；地址或来源变化时复用已保存证书。
- 界面的外部模式按用户确认连接本机系统 Nginx。通过 PATH、Homebrew 和常见 Unix 路径识别安装，读取 `nginx -V` 的默认主配置位置。
- 主配置的顶层 `http` 块加入本实例的配置引用，重复保存不重复插入；引擎数据目录保存专用片段和版本证书。片段使用本机证书路径、本机引擎上游端口及实例独立的 WebSocket 连接变量。
- 更新前验证原配置，更新后执行 `nginx -t` 和重载；失败恢复主配置和片段，必要时重载旧配置。回退失败明确报错并保留可能被进程使用的证书版本。
- 旧 API 默认保持生成外部配置的行为；界面通过 `externalLocal: true` 请求本机自动应用。
