# SSL 证书维护、Redis 新凭据与独立配置清理

日期：2026-10-08；版本 v0.3.0。

## 本轮完成

- SSL 恢复默认折叠，展开后标题、有效期提示、文件选择间保持 12px 间距。
- 证书有效期卡片窄时自动换行，删除图标保持在右侧。30 天内到期为黄色，已过期为红色，分别提示“即将到期”和“已过期”，日期使用中文格式。
- 删除按钮调用共享后端删除命令，先移除该服务 HTTPS 路由并更新／停用本实例入口，再删除对应证书和私钥文件及旧证书记录备份，保留其他服务的材料。最后一个托管证书删除后入口停止；本机外部入口清空本实例片段并重载。应用或重载失败时保留证书材料。历史本机外部配置兼容识别原片段。其他服务证书过期不阻止单独删除；新增或更换证书仍执行完整有效期校验。
- 内置 Redis 不再因已有数据卷缺失旧连接凭据而拒绝保存；优先使用本次填写的新密码，否则保留已有内置密码，缺失时生成新密码。没有删除 Redis 数据卷。保存新凭据后须重启内置 Redis 和使用它的服务使运行状态匹配新配置。PostgreSQL 既有数据凭据校验保持原样。
- 独立配置保存与规范化时清理 owner .env 的 BOX_PLAY_PUBLIC_HOST、BOX_CREATOR_HOST 及旧公共地址／协议字段。公网主机和协议从各服务自己的地址推导；迁移不会将这两个旧字段重新写回。内部运行时仍生成必要的监听和 URL 信息，本机／局域网切换可继续使用。
- Nginx 默认镜像源统一为 docker.m.daocloud.io/library/nginx:stable-bookworm，与 Redis／PostgreSQL 镜像来源一致。该镜像清单只读确认存在，并包含 Linux ARM64／AMD64；真实隔离验收使用这一镜像引用。
