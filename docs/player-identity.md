# 玩家身份与后台管理

Player Service 使用 PostgreSQL 保存玩家、会话、封禁、后台管理员和审计。

- 玩家可注册、登录、退出，修改昵称并选择内置皮肤；用户名不可修改，也不提供头像上传。
- 新账号默认“探险者”；可选飞行员、牛仔、中国娃娃、粉红女孩、女仆、小王子和圣诞女孩。
- 普通玩家同时只保留一个设备会话；新设备登录会使旧设备失效。
- 玩家账号与后台管理账号独立；服主只能通过 `BOX_PLAY_ADMIN_TOKEN` 取得临时会话，不能授权给账号。

后台管理支持搜索、标签、备注、封禁、强制下线、批量操作、权限组、管理账号、CSV 导出、审计、游玩地图、地图运行容器和资源组。公开部署时不要直接暴露后台；应放在 HTTPS、反向代理访问控制或 VPN 后。

Creator、Play、地图页面和相关 API 均校验玩家会话；未登录网页会跳转登录门户，API 返回 401。

创作者身份属于普通玩家账号的附加授权，不会把玩家变成后台管理员。服主可单独授予地图查看、新建、编辑、删除、导入、导出和模型管理权限；权限变化由 Creator、VOXA 和地图编辑入口在后续请求中重新读取，撤销后不需要等待旧登录自然过期。

## 会话与审计

玩家密码以带随机 salt 的 scrypt 摘要保存；Cookie 不可由页面脚本读取。普通玩家会话空闲 14 天失效，最长 30 天；后台管理员使用独立 Cookie，空闲 30 分钟失效，最长 12 小时。

后台可查看登录历史、活动会话、关联 IP、封禁来源和管理操作。审计只记录实际成功的敏感操作；浏览、取消弹窗或校验失败不会被记成已执行操作。后台 URL 的 `view` 参数可直接定位到已授权页面；失去权限或手动输入未授权 URL 时，界面会回退到当前身份可访问的第一页。

## 后台角色与权限组

服主通过 `BOX_PLAY_ADMIN_TOKEN` 登录，拥有全部后台能力；服主不是可创建或可分配的账号。新建管理账号时必须选择权限组，账号只能看到并调用该权限组允许的页面和 API。历史无权限组账号应尽快分配权限组，避免继续依赖兼容行为。

权限组按后台菜单分为“查看”和“编辑/管理”能力：玩家、在线会话、账号封禁、IP/设备封禁、创作权限、Creator CLI Token、游玩地图、地图容器和安全审计。选择编辑能力时，系统会自动包含对应查看能力。没有查看能力的账号不会看到相应菜单，也不能直接调用对应 API。前端隐藏菜单不是安全措施：服务端会再次校验每个请求。

权限组不得在仍被后台账号使用时删除；需先为这些账号更换权限组。删除玩家、维护后台账号和权限组仍只允许服主。

## 游玩地图与地图容器

游玩地图管理不再位于 Play 游戏内的“服主管理”。服主和拥有 `play-maps.view`/`play-maps.manage` 的后台账号可在“游玩管理 → 游玩地图”查看、导入、审查、开放和删除地图包。导入前的审查窗口会列出脚本、图片、音频等资源；Token、地图包和资源内容不会写入审计明文。

“游玩管理 → 本地资源加速”是服务器级开关，默认关闭，仅服主和管理员可查看及修改，不能通过权限组授予给普通管理员角色。开启后会为浏览器下发已发布静态资源的白名单，并使用内容 hash 区分版本；清单由 Play 主机私钥签名，浏览器会同时验证签名和资源内容 hash。客户端与服务端脚本、私有发布控制 Blob、会话和实时数据不会进入本地缓存。

“容器管理”包含游玩端、创作端和“地图容器配置”。运行状态页只显示已启动运行时，可执行销毁；地图容器配置页可按地图组或单张地图设置人数、房间数、空闲回收和资源组。资源组可创建多个，包含 CPU（m）、内存（MB）、容器进程上限、网络策略、可选出网带宽上限和资源说明；选择资源组后会以该组启动独立 Docker 容器，未选择则使用共享 Node。网络策略“仅内网”允许访问 Docker 私有网络中的数据库、Redis、玩家服务与地图控制服务，但禁止访问公网；带宽限制只限制独立容器的出网流量。

资源组绑定配置后不能删除。重启或销毁只影响选中的地图运行容器，不会删除地图文件、共享资源库、数据库数据或其他地图容器。保存资源组或地图配置只影响后续新启动/重启的运行时；不会热修改现有容器的 Docker 限制。

后台前端模块边界、权限新增步骤和验证命令见[管理后台开发说明](./player-admin-development.md)。

## Creator CLI Token

仅已获创作端访问权限的玩家可以签发 Creator CLI Token。签发结果只在成功后的单独窗口显示一次，必须立即复制保存；后台列表仅展示名称、权限、状态和最近使用信息，不能恢复 Token 明文。撤销 Token 会立即使该 Token 失效，不影响玩家账号本身。
