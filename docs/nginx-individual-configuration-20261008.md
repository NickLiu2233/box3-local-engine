# 删除共用公网地址和共用 SSL 配置

日期：2026-10-08；版本 v0.3.0。

按用户要求移除访问范围下的共用公网地址、共用 SSL 折叠栏及证书／私钥选择。各服务卡片保留自己的公网地址、SSL 证书和私钥，HTTPS 统一使用 443。相关共用地址优先级和证书说明删除，改为逐服务填写。

SSL 路由只来自各服务自己的地址，证书只来自对应服务选择的文件；不存在共用域名或共用证书的自动继承。未填写公网地址的服务不在界面生成公网链接。保存后的显式空地址在服务运行时派生为本机 HTTP URL，而不是旧共用公网域名。

为兼容现有桌面／Web 保存协议，内部 legacy 基础主机字段从已填写的服务地址派生，仅用于监听地址推导，不作为其他服务的公网 URL。旧 API 和已保存证书材料保留读取兼容；此轮没有删除用户证书文件、改真实域名或重启业务服务。

验证：共享后端 100 项通过、2 项原有隔离验收默认忽略；界面与传输 45 项通过，覆盖共用入口和字段移除、逐服务 URL／证书提交、服务之间证书隔离、地址不继承、本机／局域网切换、旧证书复用及未安装 Nginx 时保存提示。界面结构检查与生产构建通过。

候选包包含未提交修改，属于 macOS ARM64 测试包，ad-hoc 签名，未 Apple 公证；服务镜像未重建，Web 管理器未部署更新。

桌面保存端明确写入空地址字段；Web 保存端补齐逐服务地址写入及读取返回字段，避免重新加载时丢失独立地址。新增 Web 纯保存链路回归通过。
